Key Rightsizing Principles

💾
Memory First
Model weights must fit in GPU VRAM. A 70B FP16 model needs ~140 GB — plan for multi-GPU tensor parallelism or quantization.
⚡
Bandwidth Over FLOPS
Inference is memory-bandwidth-bound, not compute-bound. Prefer GPUs with high HBM bandwidth (e.g., H100: 3.35 TB/s) for low-latency serving.
🌡️
Thermal & Power Budget
Dense GPU racks (400–1000 W/GPU) require liquid cooling. Plan facility power and cooling before hardware procurement.
🔀
Heterogeneous Pools
Separate training, inference, and embedding GPU pools. Mixed fleets (e.g., H100 + L40S) optimize cost and utilization across workload types.
📐
Quantization Leverage
INT8 / INT4 quantization can halve VRAM requirements with minimal quality loss — enabling a smaller (cheaper) GPU tier for many inference workloads.
📊
Profile Before Scaling
Measure actual GPU utilization, memory usage, and latency under realistic load before scaling out. Idle GPU time is wasted CapEx.
